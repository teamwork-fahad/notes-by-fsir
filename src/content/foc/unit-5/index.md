# Unit 5: Open Office Suite

## Overview

Open Office is a free and open-source office productivity suite that provides tools for word processing, spreadsheets, and presentations. It is compatible with various file formats.

---

## 5.1 Open Office Writer

Open Office Writer is a word processor used for creating and formatting documents.

### 5.1.1 Working with Documents

- **Creating Documents**: Start a new blank document or use templates
- **Saving Documents**: Save in .odt format or export to .doc, .docx, .pdf
- **Opening Documents**: Open existing documents or recent files
- **Document Properties**: Set title, author, subject, keywords

### 5.1.2 Formatting Documents

- **Text Formatting**: Bold, italic, underline, strikethrough
- **Font Management**: Change font type, size, and color
- **Paragraph Formatting**: Alignment (left, center, right, justify), line spacing, indentation
- **Lists and Numbering**: Create bullet points and numbered lists
- **Highlighting**: Apply background color to text

### 5.1.3 Setting Page Style

- **Page Setup**: Define page size, margins, and orientation (portrait/landscape)
- **Headers and Footers**: Add recurring content at top/bottom of pages
- **Page Breaks**: Insert manual breaks between pages
- **Columns**: Arrange text in multiple columns

### 5.1.4 Creating Tables

- **Table Insertion**: Create tables with specified rows and columns
- **Table Formatting**: Modify cell appearance, borders, and background
- **Cell Operations**: Merge, split, and resize cells
- **Table Navigation**: Move and select cells efficiently

### 5.1.5 Drawing Tools

- **Basic Shapes**: Rectangles, circles, lines, arrows
- **Text Boxes**: Insert text in custom positions
- **Connectors**: Link shapes with connecting lines
- **Grouping**: Combine multiple shapes

### 5.1.6 Printing Documents

- **Print Preview**: View how document will look when printed
- **Print Settings**: Select printer, page range, number of copies
- **Print to PDF**: Export document as PDF file

---

## 5.2 Open Office Calc

Open Office Calc is a spreadsheet application for data analysis and calculations.

### 5.2.1 Introduction to Spreadsheets

Spreadsheets are tables of data organized in rows and columns, used for:
- Data entry and management
- Mathematical calculations
- Financial analysis
- Data visualization

### 5.2.2 Overview of a Worksheet

- **Cells**: Individual data storage units (identified by column and row)
- **Rows and Columns**: Horizontal and vertical divisions of the worksheet
- **Sheet Tabs**: Navigate between multiple sheets in a workbook
- **Formula Bar**: Display and edit cell contents

### 5.2.3 Creating Worksheet & Workbooks

- **Create New Workbook**: Start a new spreadsheet file
- **Add Worksheets**: Insert additional sheets into a workbook
- **Sheet Naming**: Rename sheets for better organization
- **Blank Templates**: Start with empty worksheets

### 5.2.4 Organizing Files, Managing Files & Workbooks

- **File Operations**: Create, open, save, close files
- **Save Formats**: Save as .ods, .xls, .xlsx
- **File Properties**: Set document metadata
- **Backup**: Create backup copies of important files

### 5.2.5 Functions & Formulas

- **Basic Formulas**: Mathematical operations (+, -, *, /)
- **Built-in Functions**: SUM, AVERAGE, COUNT, MIN, MAX
- **Logical Functions**: IF, AND, OR conditions
- **Text Functions**: CONCATENATE, UPPER, LOWER
- **Referencing**: Absolute and relative cell references

### 5.2.6 Working with Multiple Sheets

- **Sheet Navigation**: Switch between worksheets
- **Cross-sheet References**: Reference cells from other sheets
- **Sheet Organization**: Arrange sheets logically
- **Data Consolidation**: Combine data from multiple sheets

### 5.2.7 Creating Charts & Printing Charts

- **Chart Types**: Column, bar, line, pie, area charts
- **Chart Creation**: Select data and generate charts
- **Chart Customization**: Modify titles, legends, labels
- **Chart Printing**: Print charts with or without source data

---

## 5.3 Open Office Impress

Open Office Impress is a presentation software for creating slideshows.

### 5.3.1 Creating Presentation, Saving Presentation Files

- **New Presentation**: Create from blank or template
- **Slide Addition**: Add slides to presentation
- **Save Formats**: Save as .odp or export to .pptx
- **Presentation Properties**: Set author, title, subject

### 5.3.2 Master Templates & Re-usability

- **Master Slides**: Define template design for entire presentation
- **Slide Layouts**: Use predefined or custom layouts
- **Template Reuse**: Save and use presentation templates
- **Design Consistency**: Apply uniform formatting across slides

### 5.3.3 Slide Transition

- **Transition Effects**: Add visual effects between slides
- **Transition Speed**: Control transition duration
- **Advance Settings**: Manual or automatic slide advancement
- **Sound Effects**: Add audio to transitions

### 5.3.4 Making Presentation CDs

- **Export for Distribution**: Save presentation for CD distribution
- **File Format**: Convert to formats suitable for different platforms
- **Compatibility**: Ensure presentation runs on various systems
- **Packaging**: Include necessary files and components

### 5.3.5 Printing Handout

- **Handout Printing**: Print multiple slides per page
- **Notes Printing**: Print speaker notes with slides
- **Print Settings**: Configure handout layout and spacing
- **Preview**: Review printed layout before printing

---

## Summary

Open Office Suite provides powerful tools for word processing, data analysis, and presentations, all available for free. Mastering these applications enables efficient document creation, data management, and professional presentation delivery.
