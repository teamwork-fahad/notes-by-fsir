## Short Description

### POP
**Procedure-Oriented Programming (POP)** focuses on **functions or procedures**. A program is divided into different functions that perform specific tasks.

### OOP
**Object-Oriented Programming (OOP)** focuses on **objects and classes**. Data and functions are combined together inside objects.

**In short:**  
> **POP → Focuses on functions**  
> **OOP → Focuses on objects**

# Difference Between POP and OOP

| Feature | POP (Procedure-Oriented Programming) | OOP (Object-Oriented Programming) |
|---|---|---|
| **Full Form** | Procedure-Oriented Programming | Object-Oriented Programming |
| **Main Focus** | Functions / Procedures | Objects and Classes |
| **Approach** | Top-down | Bottom-up |
| **Program Division** | Divided into functions | Divided into classes and objects |
| **Data Security** | Less secure | More secure due to encapsulation |
| **Data & Functions** | Data and functions are generally separate | Data and functions are combined in objects |
| **Reusability** | Less reusable | Highly reusable |
| **Inheritance** | Not supported | Supported |
| **Polymorphism** | Not supported | Supported |
| **Encapsulation** | Not available as a core feature | Supported |
| **Abstraction** | Limited | Supported |
| **Examples** | C, Pascal, FORTRAN | C++, Java, Python, C# |
| **Best Suited For** | Small and simple programs | Large and complex programs |
