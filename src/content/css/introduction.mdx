# Introduction to CSS

CSS (Cascading Style Sheets) is used to control the visual presentation of HTML content, such as colors, layout, and fonts.

## What does CSS do?

CSS lets us define:

- Colors and typography
- Spacing and layout
- Responsive design
- Animations and transitions

## Example

```css
body {
  font-family: sans-serif;
  background-color: #f5f5f5;
}

h1 {
  color: #2563eb;
  text-align: center;
}
```

## Selectors

```css
/* Class selector */
.card {
  padding: 1rem;
  border-radius: 8px;
}

/* ID selector */
#header {
  font-weight: bold;
}

/* Element selector */
p {
  line-height: 1.6;
}
```
