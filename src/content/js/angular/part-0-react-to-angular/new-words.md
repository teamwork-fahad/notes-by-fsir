# Part 0 — New Words

Dotted words with a small **?** in lessons are new words.

Hover (or tap) them to see a short meaning.

This page collects the main words in one place.

:::tip
You do not need to memorize everything now.
Read the short meaning, then continue the lesson.
:::

## A–D

| Word | Easy meaning |
| --- | --- |
| **API** | A way for your app to ask a server for data |
| **Attribute directive** | Changes how an element looks or behaves |
| **Component** | A small reusable UI part (button, card, page section) |
| **Conditional rendering** | Show or hide UI based on a true/false condition |
| **Data binding** | Connecting component data with the HTML template |
| **Decorator** | A special marker like `@Component` that adds meaning to a class |
| **Dependency Injection (DI)** | Angular gives your component the tools/services it needs |
| **Directive** | An instruction that tells Angular how to change HTML |

## E–L

| Word | Easy meaning |
| --- | --- |
| **Event** | Something the user does, like click or type |
| **EventEmitter** | Angular tool that sends an event from child to parent |
| **Framework** | A bigger ready-made structure with many built-in tools |
| **Frontend** | The part of the website the user sees and clicks |
| **HttpClient** | Angular’s built-in tool for calling APIs |
| **Interpolation** | Showing a value in the template with `{{ }}` |
| **Library** | A tool focused on one job (React focuses on UI) |
| **Lifecycle hook** | Code that runs at a stage of a component’s life |

## O–S

| Word | Easy meaning |
| --- | --- |
| **Observable** | A stream of data that can arrive now or later |
| **Props** | Data passed from parent to child in React |
| **Routing** | Showing different pages based on the URL |
| **RxJS** | A library for working with data streams |
| **Service** | A reusable class for shared logic or API code |
| **Standalone component** | A modern Angular component that does not need NgModule |
| **State** | Data that can change while the app runs |
| **Structural directive** | Adds or removes HTML structure (`*ngIf`, `*ngFor`) |

## T–Z

| Word | Easy meaning |
| --- | --- |
| **Template** | The HTML part of an Angular component |
| **Type safety** | Checking that values match the expected type |
| **TypeScript** | JavaScript with types |
| **Two-way binding** | Input and data stay in sync both ways (`[(ngModel)]`) |
| **`@Input()`** | Receive data from parent to child in Angular |
| **`@Output()`** | Send an event from child to parent in Angular |
| **`*ngFor` / `@for`** | Loop and show a list |
| **`*ngIf` / `@if`** | Show content only when a condition is true |
