📌 Question 5: Find Q₁ and Q₃
Problem Statement: Find $Q_1$ and $Q_3$ from the following data:
Class20–2525–3030–3535–4040–4545–50
Frequency ($f$)51215855
💡 Easy Guide / आसान तरीका:
- $Q_1$ (Lower Quartile) = data ka $25\%$ mark $\implies$ position $\frac{N}{4}$.
- $Q_3$ (Upper Quartile) = data ka $75\%$ mark $\implies$ position $\frac{3N}{4}$.
- Formula: $Q_k = L + \left(\frac{\frac{k \cdot N}{4} - cf}{f}\right) \times h$.
1 Step 1: Construct Cumulative Frequency Table

2 Step 2: Calculate First Quartile ($Q_1$)

1. Position of $Q_1$: $\frac{N}{4} = \frac{50}{4} = 12.5$.

2. $cf$ just greater than $12.5$ is 17 $\implies$ $Q_1$ Class = 25–30.

  • Lower limit ($L$) = $25$
  • Preceding $cf$ ($cf$) = $5$
  • Frequency of class ($f$) = $12$
  • Class length ($h$) = $5$
$$Q_1 = L + \left( \frac{\frac{N}{4} - cf}{f} \right) \times h$$ $$Q_1 = 25 + \left( \frac{12.5 - 5}{12} \right) \times 5 = 25 + \left( \frac{7.5}{12} \right) \times 5 = 25 + \frac{37.5}{12} = 25 + 3.125 = \mathbf{28.125}$$
3 Step 3: Calculate Third Quartile ($Q_3$)

1. Position of $Q_3$: $\frac{3N}{4} = \frac{3 \times 50}{4} = 37.5$.

2. $cf$ just greater than $37.5$ is 40 $\implies$ $Q_3$ Class = 35–40.

  • Lower limit ($L$) = $35$
  • Preceding $cf$ ($cf$) = $32$
  • Frequency of class ($f$) = $8$
  • Class length ($h$) = $5$
$$Q_3 = L + \left( \frac{\frac{3N}{4} - cf}{f} \right) \times h$$ $$Q_3 = 35 + \left( \frac{37.5 - 32}{8} \right) \times 5 = 35 + \left( \frac{5.5}{8} \right) \times 5 = 35 + \frac{27.5}{8} = 35 + 3.4375 = \mathbf{38.4375}$$

✅ Final Answer:

  • First Quartile ($Q_1$) = 28.125
  • Third Quartile ($Q_3$) = 38.4375
